
# Atividades Acadêmicas em C

Repositório destinado ao armazenamento e à organização de exercícios e atividades acadêmicas desenvolvidos em linguagem C durante a graduação em Engenharia de Software.

## Objetivo

Registrar minha evolução no aprendizado de lógica de programação e dos fundamentos da linguagem C, reunindo exercícios, práticas e conteúdos estudados ao longo da disciplina.

## Conteúdos estudados

- Introdução à programação.
- Variáveis e tipos de dados.
- Operadores aritméticos e relacionais.
- Estruturas condicionais.
- Estruturas de repetição.
- Funções.
- Vetores e matrizes.
- Ponteiros.
- Arquivos
- Structs

## Tecnologias utilizadas

- Linguagem C.
- Compilador C (DevC++).

## Formação

**Curso:** Engenharia de Software  
**Instituição:** UNIPÊ — Centro Universitário de João Pessoa.
